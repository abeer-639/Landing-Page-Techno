# Techno — Landing Page

A modern and responsive landing page built **from scratch** using Next.js, TypeScript, and Tailwind CSS.

The project focuses on creating a clean and modern user interface with carefully structured sections, responsive layouts, and smooth animations.

> **Techno is a frontend-only landing page. It does not include backend logic, database integration, authentication, or complex business logic.**

live demo : https://landing-page-technology.netlify.app/

---

## ✨ Project Overview

**Techno** is a manually developed landing page designed to present a modern technology-oriented website.

The entire interface was built from scratch with a focus on:

* Clean and structured UI
* Responsive design
* Reusable components
* Smooth animations and transitions
* Modern visual presentation
* Maintainable frontend architecture

No ready-made website template was used.

---

## 🧩 Sections

The landing page consists of the following main sections:

### Navbar

Responsive navigation bar providing access to the different sections of the landing page.

### Hero

The main introductory section designed to immediately present the website and its primary message.

### About

A section introducing the project/company and providing additional information.

### Services

Displays the services offered through a clean and structured layout.

### Features

Highlights the main features and benefits using visually organized content.

### Team

Presents the team members in an interactive and visually consistent layout.

### Pricing

Displays available pricing plans in a clear and responsive pricing layout.

### Footer

Contains additional navigation, information, and supporting links.

## 🚀 Getting Started

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open the project in your browser:

```text
http://localhost:3000
```

---

## 📦 Production

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm run start
```
